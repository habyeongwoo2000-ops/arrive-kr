# ArriveKR · 외국인근로자 한국 입국 준비 체크리스트

> 동북권 오픈소스 아이디어톤 · 주제: 지역 주민 맞춤형 공공지원사업 추천 서비스
> 팀 안병잘부 (상지대학교)

**지구본에서 내 나라를 누르면, 한국(인천공항)까지 비행 경로가 그려지고
경로 위 구간마다 준비할 서류와 기한을, 위험한 구간은 "난기류"로 보여 주는 입국 체크리스트**입니다.
한국어 · English · Tiếng Việt · Bahasa Indonesia · ខ្មែរ · नेपाली

## 화면

| 기능 | 설명 |
|---|---|
| 실제 지구본 | NASA Blue Marble 위성 사진 + 지형 굴곡 + 대기 + 별 배경. 마우스로 돌리고 확대. 왼쪽 아래 버튼으로 **위성 ↔ 지도**(구글 지도처럼 하늘색 바다·회색 땅) |
| 나라 선택 | 지구본에서 누르거나 왼쪽 위 검색창에서 검색. 고용허가제(E-9) 송출국 18개는 EPS 표시 |
| 경로 | 출발(수도) → ① 출발 준비 → ② 한국어·기능 시험 → ③ 건강검진·선발 → ④ 출국 준비 → ⑤ 한국 도착 후 |
| 체크리스트 | 구간마다 할 일과 설명, 그 나라 송출기관이 더 요구하는 서류(사진 용량·신분증 등) |
| ⛽ 연료 | 입국 예정일을 넣으면 항목마다 "언제까지 · D-몇"과 남은 준비 기간 게이지(여유 / 빠듯함 / 늦음) |
| ✈ 비행 · 난기류 | "비행 시작"을 누르면 비행기가 경로를 따라가고, 위험 구간(여권 이름 불일치, 브로커, 사진 규격, 건강검진, 위조 서류, 도착 후 기한)에서 화면과 비행기가 흔들리며 경고 카드가 뜸 |
| 가 한국어 시험 도우미 | EPS-TOPIK 연습 문제 12개(직장·안전 어휘). 힌트는 고른 나라의 언어로. "AI에게 묻기"는 Gemini 로 답함 |
| 로그인 | 아이디·비밀번호로 계정을 만들면 체크 기록·입국 예정일·나라가 계정별로 저장 |

## 데이터 (확인일 2026-11-08)

- `src/data/countries.js` — 송출국 18개: 송출기관·누리집·응시료·추가 서류·나라별 위험, **확인 수준**(공지 원문 / 정리 글 / 송출기관만)
  - 원문 확인: 필리핀(DMW), 스리랑카(SLBFE), 우즈베키스탄(gov.uz) · 정리 글로 확인: 네팔, 인도네시아(2025), 방글라데시
  - 나머지는 송출기관 목록만 확인 → 화면에 "공지 확인 필요"로 표시
- `src/data/route.js` — 구간·항목·난기류(6개 언어). 근거: 한국산업인력공단 고용허가제 안내, 외국인고용법 제7·9·10·11조, 출입국관리법 제31조
  - 항목의 `lead`(입국 며칠 전까지)는 공식 기한이 아니라 권장 준비 기간입니다.
- E-9 송출국이 아닌 나라는 일반 취업 비자(E-7 등) 기본 흐름만 보여 줍니다.
- 나라 경계: Natural Earth(world-atlas) · 지구 사진: NASA Blue Marble(three-globe 예제 이미지)

## 실행 · 배포

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
```

Vercel: 저장소 Import → Deploy. `api/tutor.js` 는 Vercel 함수로 자동 배포됩니다.

| 환경변수 | 용도 |
|---|---|
| `GEMINI_API_KEY` | 한국어 도우미 "AI에게 묻기" (없으면 연습 문제만 동작) |
| `GEMINI_MODEL` | 선택. 기본 `gemini-2.5-flash` |

## 로그인에 대해 (데모)

서버 없이 **이 브라우저 안에만** 계정을 만듭니다. 비밀번호는 PBKDF2(SHA-256, 120,000회)+소금으로 바꿔 저장하지만,
다른 기기와 공유되지 않습니다. 실제 운영에서는 `src/lib/auth.js` 를 Supabase Auth 등 서버 로그인으로 바꾸세요.

## 다른 나라·체류자격으로 넓히기

`countries.js` 에 나라를, `route.js` 에 체류자격(E-8 계절근로, H-2 방문취업 등)별 구간을 더하면 됩니다.
